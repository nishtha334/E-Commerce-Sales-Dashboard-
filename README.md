# E-Commerce Sales Dashboard

A comprehensive dashboard for tracking and analyzing e-commerce sales metrics and performance.

## Features
- Sales analytics
- Customer insights
- Order tracking
- Performance metrics

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
```bash
git clone https://github.com/nishtha334/E-Commerce-Sales-Dashboard-.git
cd E-Commerce-Sales-Dashboard-
npm install
```

### Running the Dashboard
```bash
npm start
```
